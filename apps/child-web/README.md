# Child Web

儿童数学学习前端。

## Current release
`1.2.0` — Learning Result Closure

## Run
From repository root:

```bash
npm install
npm run child:dev
```

Or from this directory:

```bash
npm install
npm run dev
```

## Main routes

- `/child/math`
- `/child/math/session/[sessionId]`
- `/child/math/result/[sessionId]`
- `/child/math/growth`
- `/dev/ui-kit`
