# Onboarding

## New human / AI worker

15分钟内完成：

1. 读根目录 README
2. 读 PROJECT_STATUS
3. 读 ROADMAP
4. 读 Contract Drift Register
5. 读相关 ADR
6. 在本地运行：
   ```bash
   npm install
   npm run governance:check
   npm run release:check
   npm run child:typecheck
   ```
7. 只从最新 main 开分支
8. 领取一个明确 Issue 后开始修改

不要从旧 ZIP 开发。
