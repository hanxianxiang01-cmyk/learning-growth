`clock` 是 V1.4 Renderer Registry 的独立 V2 Renderer。当前为 planned；实现后必须遵守 Registry → TaskRenderer → Workspace → TaskResponse → MathResponse V2 → AttemptResult 的统一链路。

2. 功能范围
围绕“读时、拨针、时间关系”完成题目专属交互。
配置与运行态分离：config / initial_state / present。
支持通用 Runtime 的 history、undo、reset、interaction_events。
输出标准化 answer 与 workspace data。
即时 Evaluator 仅负责交互反馈，不负责 mastery/Diagnosis 权威判断。

5. 事件模型
建议关键事件：`HAND_MOVED / TIME_SET / UNIT_CHANGED / RESET / UNDO`。事件用于 Evidence/行为诊断，不直接决定 mastery。
6. Evaluator / Diagnosis 边界
PASS / PARTIAL / FAIL / INVALID 可用于即时 UI 反馈。
FAIL 必须允许提交；错误答案本身是诊断证据。
PARTIAL / INVALID 在不能形成合法答案时可阻止提交。
Diagnosis、mastery、学习策略由后端权威链路决定。

9. Vertical Gate / Definition of Done
Registry → TaskRenderer 解析正确，真实页面无静默降级。
Workspace 可稳定序列化，核心交互有事件记录。
TaskResponse → MathResponse V2 → AttemptResult 闭环通过。
正确、错误两类 attempt 均有真实 E2E。
错误 attempt 能进入 Diagnosis / Retry。
ui_revision、workspace_id、attempt_no 可追踪。
