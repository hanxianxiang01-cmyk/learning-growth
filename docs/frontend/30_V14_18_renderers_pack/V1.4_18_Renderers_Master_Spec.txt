2. 统一开发合同
所有 Renderer 使用 V2 Schema；禁止静默降级。
共享 Renderer Runtime 的 Workspace / history / events / undo / reset。
错误答案必须可提交；FAIL 不等于禁止提交。
Renderer 不负责 mastery、Diagnosis 权威判断。
Response 统一通过 v2AttemptAdapter。
每个 Renderer 必须完成真实页面 E2E，不能以纯函数测试替代。
