## 二、整改出路（每题二选一，不得只改 ability_id 字段）

**出路 A：修成检验闭环题**（推荐，保 M30 归属）。示例改写口径：
- ruler 两题 → "小明说这条线段长 7 厘米（端点 4 到 10）。他说的对吗？请用尺子验证并选出：对 / 错，正确答案是__"——answer 形态需继续满足标量契约（G1），判定+正确值可编码为单一标量或拆两题
- estimation 两题 → "小红估这堆散点约 40 个。她的估计在容差内吗？（容差已在画布标出）选：合理 / 不合理"——利用现 tolerance 字段做客观核验
- pattern 两题 → "下面是按规律填好的板子：3,1,3,1,**3,3**。最后一格填得对吗？对填 1，错填正确的数"——给错误续排让孩子纠偏

**出路 B：按实质能力重归属**——承认六题实为 M35/M36（测量）、M06（估数）、M42 类（规律），改 `source_skill_id` + `ability_id` + 溯源记录。注意：
- 改 source_skill_id=触发映射表适用重审（新 M 号须在该技能批准范围内）
- **M42 归属题须带真实 `is_transfer` 行为依据**（FE-1439 §4：3,108 批 M42 有 68 题无迁移行为不得挂 transfer；整改题同样按此口径）
