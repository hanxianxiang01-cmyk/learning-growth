# QA-ACCESS-01 Shape Gallery 无障碍等效识别（独立验收项）

**来源**：Q4 Rev.A 整改裁决 §二（产品方 2026-10-16）+ 开发侧实证（aria-label 现状全 null）。
**定位**：与 Q4 教研审核**并行**，不阻塞文档/脚本合并；但 **9 题不得据此宣布"所有使用方式均已通过验收"**。

## 背景事实（开发侧证据）
- 整改前：卡面可见文字=`红正方形`/`正方形卡3` 等 → 屏幕阅读器可从可见文字生成可访问名称，但**直接播报分类答案**；
- 整改后：可见文字=`卡1…卡6`（泄露清零，E2E 实证）→ **无显式 aria-label**（实测全 null），屏幕阅读器现在**只能读出编号**，孩子无法在不依赖视觉的情况下获知图形特征——**中性化把无障碍问题从"泄题"翻转成"不可用"**；
- 图形本身是 emoji 字形（`SHAPE_EMOJI[kind]`），同屏阅读器读法同样不稳定。

## 验收标准（产品方定义）
> 儿童在**不依赖视觉**的情况下，能获得**足以完成形状分类**的图形描述，**同时不直接播报分类答案**。

两条都要过：可用性（描述足够判断 kind）× 不泄题（描述≠"正方形"等类别标签词——注意：形状描述必然涉及几何特征词，**边界=特征≠分类结论**，如"四条边一样长的图形"可接受，直接"正方形"不可接受——最终口径由教研定）。

## 工作内容
| 步 | 事项 | 负责 |
|---|---|---|
| 1 | 描述文案设计：每个 kind 的特征描述（边数/角/对称等儿童语言版），**不含分类结论词** | 教研 |
| 2 | 实现：`ShapeGalleryV2` 按钮 `aria-label`=特征描述；`sg-home` 区域 `aria-label` 含目标特征（"放进四条边一样长的家"）；图形 emoji 加 `aria-hidden`（防乱读） | 前端 |
| 3 | 键盘链路同步验收：纯键盘操作（Tab+Enter）能否完成同一任务（无障碍≠只读屏） | 前端+E2E |
| 4 | E2E 断言：sg-shape 按钮 aria-label 非空且不含四类标签词；home aria-label 含特征；屏幕模拟（axe 或文本比对） | QA |
| 5 | 9 题（现行新 rvid 见 Q4_rvid_migration_12.csv）逐题过 3、4 | QA |
